# 0.5.1 跨螢幕拖曳預覽修正

舊版直接在桌面反向繪製虛線，桌面／動態桌布重繪時會擦掉線條。
拖曳起點讀取最新滑鼠位置，而非按下時的位置；快速操作時起點可能已經改變。
此外，預覽顯示未限制的矩形，放開後才套用目標螢幕工作區，兩者位置不同。

新版拖曳期間建立透明預覽視窗，用固定實體像素定位，忽略換螢幕時的
自動尺寸變更。框線有黃色前景與黑色襯線，在桌布上保持可辨識。
此視窗不取得焦點、不攔截滑鼠；放開、取消、失去滑鼠捕捉或關閉籃框便銷毀。
沒有新增待機計時器、輪詢或常駐預覽視窗。

按下的位置依該次滑鼠訊息換算，移動及放開使用最新實體游標座標。
預覽先套用目標螢幕工作區、格數縮放、磁吸與折疊規則，放開直接提交
相同位置；跨到無法容納的工作區顯示紅色框，不移動原籃框。

## 驗證

- 48 項預覽檢查：上／左負座標螢幕、螢幕邊界與工作列、縮小工作區、
  折疊尺寸、實際雙螢幕的原生視窗座標、重繪、穿透、焦點、資源釋放、
  預覽與落點一致、LOCK、目標螢幕消失。
- 保留原版的雙螢幕、LOCK、視窗按鈕、選取、右鍵路由及佈局測試。
- 滑鼠驗證使用兩個隔離的測試桌面與空籃框，不改動個人桌面位置或檔案。
- 滑鼠工具限制只能在單一視窗邊界內拖曳；跨到另一個螢幕的實際操作
  另以測試籃框的拖曳紀錄檢查，不把座標規劃測試當成完整的滑鼠驗證。
- 使用者已確認「預覽正常，落點一致」。第二個測試場景記錄 5 次完成拖曳、
  922 筆預覽取樣；原生位置全部與計畫位置一致，每次落點一致，放開後
  預覽視窗均已釋放。
- 共享功能 31 項檢查通過；桌面回歸 6 組通過。涉及共用剪貼簿的框選
  測試單獨重跑通過，避免與其他測試同時寫入剪貼簿。
