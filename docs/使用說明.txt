螢幕變更通知會合併後處理；使用 Windows 實際螢幕識別與實體工作區，避免快取或 DPI 虛擬座標錯誤。
螢幕暫時過小或不可用時，不再拋出 FitProportional 未處理例外。無法安置所有籃框時安全暫停並還原桌面圖示，保留原位置與大小。

變更後最多八次短暫重試，完成後停止，不增加閒置輪詢。檔案路徑、分類歸屬與 LOCK 狀態保持不變。

既有更新：登入 Windows 後自動啟動並開啟籃子
分類管理左下角勾選「登入 Windows 後自動啟動並開啟籃子」，立即儲存至目前帳號的 Windows 啟動設定。

即使上次暫停了桌面，登入啟動仍會開啟已儲存的籃子。取消勾選只停止下次自動啟動，不關閉目前籃子。
啟動時若 Explorer 尚未就緒，最多重試 30 次；成功後不留下啟動輪詢或背景工作。
設定只作用於目前帳號，不需要系統管理員權限；解除安裝會移除這個啟動項目，分類設定與原始檔案仍保留。
ZIP 版也支援此開關，但開啟後請保持程式資料夾位置不變；搬動後重新勾選更新啟動路徑。

既有修正：桌面自動排列空洞
啟動分類、加入檔案、調整籃框及桌面重新整理時，未分類圖示依目前的直欄順序補齊所有可用格，包含既有空洞。
格距與起點沿用 Explorer 的實際桌面格線；籃框及文字避讓範圍保留，不把圖示移到其他螢幕。
桌面新增、刪除與重新命名以事件觸發整理，不增加待機輪詢；重複整理已排好的桌面不再移動圖示。
直接拖回桌面的項目仍保留落點附近的位置；下一次分類或重新整理才重新補齊。
自動排列只調整桌面圖示座標，檔案路徑與籃框內的分類保持不變。

既有更新：籃框內圖片縮圖
圖片在籃框內顯示 Windows Shell 提供的縮圖預覽，保持原圖比例；透明 PNG 保留透明背景。
本機驗證 PNG、JPEG、BMP、GIF、TIFF；其他格式需 Windows 已有對應縮圖提供者。不支援或損壞的圖片保留一般圖示。
背景只處理目前顯示的項目，縮圖載入後只重畫檔案格，不重建或隱藏籃框。
圖示／縮圖快取最多 64 個項目，每張縮圖不超過 64 × 48 px；背景佇列最多 64 筆，處理完執行緒退出，不持續輪詢。
桌面圖片在原路徑儲存修改後會更新預覽；進入微待命清空快取，待下次使用重新載入。
原始圖片沒有搬移、改名或複製，產生縮圖後不會鎖住原檔。

視窗按鈕在滑鼠放開事件完成後執行，避免 Windows 因按鈕仍擷取滑鼠而忽略指令。

既有功能：LOCK 鎖定與游標
點擊黃色鎖頭或旁邊的 STATUS 文字即可鎖定／解鎖。透明底板上的點擊與放開會正確送到同一控制項。
鎖定後，標頭、邊框、八個縮放邊角及黃色分類旗角維持一般箭頭，只有 LOCK 控制保留手形游標。
鎖定時不能拖曳框的位置或大小，雙擊標頭不再誤開編輯。框內檔案仍可框選、拖曳、捲動及使用原生右鍵。
進入微待命後仍顯示 LOCKED；點擊鎖頭可直接喚醒及解鎖，不增加閒置輪詢。

籃框內框選與多選
在檔案區空白處按住左鍵拖曳，即可框選；選取框只顯示在內側檔案區。
Ctrl 點擊增減選取；Shift 點擊連續選取；Ctrl + A 全選（包含捲動區外的項目）。
Ctrl 框選反轉框內項目的選取；Shift 框選加入目前選取；Esc 取消正在進行的框選或清除選取。
方向鍵移動選取；Shift + 方向鍵延伸選取；Ctrl + 方向鍵移動焦點，Ctrl + 空白鍵切換焦點項目的選取。
右鍵已選取的檔案會保留多選，使用 Windows 原生選單處理所有選取項目；右鍵未選取檔案則選取該檔案。
拖曳已選取的任一圖示，可把整組移到另一籃子；整組都是桌面來源時，也可拖回桌面空白處。
Delete 延續既有行為：移出視覺分類，原檔不會刪除。刪除原檔請使用原生右鍵的「刪除」。
框選不搬動檔案、不改路徑；選取狀態不寫入分類設定，沒有新增待命輪詢或動畫。

文字與真實資料
01、02：分類的連續編號；新增、移除分類後重新編號。
WORKSPACE：你的分類名稱；雙擊標題可自行改名。
OBJECTS：此分類實際項目數；加入、移除、跨分類移動時更新。
STATUS：READY、LOCKED、STANDBY，對應可用、鎖定與微待命狀態。
OBJECT GROUP / LOCAL STORAGE SECTOR：目前桌面上的本機視覺分類。
SYS: LOCAL：本機設定資料；SECTOR：實際分類編號。
LOCAL / DISPLAY：框所在的實際螢幕。
GRID：實際橫向與直向格數；PATH: ORIGINAL：原始路徑不變。
REV：設定檔儲存修訂次數；日期：最後儲存日期；VER：程式版本。
預覽 PNG 使用驗證檔案與實際計數，並非你的桌面檔案截圖。

原始路徑
拖入桌面檔案、資料夾或捷徑後，只改變視覺分類與桌面圖示顯示。
不搬移、複製、重新命名原檔，也不建立額外捷徑。
例如 C:\Users\Player\Desktop\遊戲.lnk，分類前後路徑完全相同。
其他程式與檔案總管仍可透過原本路徑找到檔案。
原生桌面圖示會在籃子中顯示，框外不會再多顯示一份。

操作
捷徑顯示名稱隱藏 .lnk、.url、.website、.appref-ms 副檔名；一般檔案與資料夾名稱不變。原始檔名和路徑保留。
雙擊框內項目開啟；右鍵開啟 Windows Shell 原生選單。
將框內桌面項目直接拖到桌面空白處，放開後顯示原生圖示；原始檔案路徑與內容保持不變。
拖到另一個籃子即可跨籃分類；拖曳中按 Esc 取消。外部路徑的連結不會搬到桌面。
拖曳標頭移動；靠近其他框 16 px 內，會磁吸貼齊或對齊邊緣。
拖曳四邊、四角或右下十字縮放。大小吸附完整格數，並盡量保持原框比例。
預設 14 × 4 格；最小 5 × 1 格。這台桌面最小 476 × 250 px，原本為 932 × 501 px，寬、高約各縮至一半。小尺寸會重新排列真實資訊文字，保留框線與裝飾，圖示間距不縮小；超過五個檔案可捲動。
這台桌面的原生圖示間距為 76 × 99 px，框內沿用此間距。
檔案超過可見格數，可使用滾輪、右側細捲動條、方向鍵與 PageUp/PageDown。
點擊黃色狀態圓點可鎖定／解鎖位置和大小。鎖定不妨礙加入檔案、開啟或捲動。
右上黃色旗角是分類選單，可改名、加入桌面檔案、鎖定、收合及移除分類。
分類設定可調整玻璃底色濃度 40–100%，預設 68%。底色獨立透明，文字與圖示保持不透明。
玻璃使用靜態暗色漸層與細微反光，桌布會透過玻璃底板顯示。
新增或移動框會先把被擋住的未分類桌面圖示擠開，再顯示整理框。
如果空間不足，操作不套用；原始檔案仍留在原位。
移除分類只取消分類；「暫停並還原圖示」或退出程式還原桌面圖示位置和排位設定。
關閉管理視窗會藏到系統匣；點系統匣可重新開啟。
