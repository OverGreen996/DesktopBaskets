Desktop Baskets 0.4.3 — Windows 桌面純視覺分類工具

更新：先在舊版程式內選「退出並還原圖示」，再執行本資料夾的 DesktopBaskets.exe。使用相同的本機設定，原有分類會保留。不要同時啟動兩個版本。
執行 DesktopBaskets.exe，保留同目錄的 .config、Newtonsoft.Json.dll 與 Assets。
支援 Windows x64，使用系統 .NET Framework 4.8；不使用瀏覽器引擎。

取消獨立的 Windows 彩色標題列，視窗控制直接整合到原有標頭，同底色、沒有額外標題列色帶。
右上角為向量繪製的最小化、最大化／還原、關閉按鈕；支援鍵盤焦點。
拖曳標頭可移動，雙擊標頭可最大化／還原；四邊、四角可縮放。最大化的可見介面避開工作列。
關閉鈕藏到系統匣並保留分類；「關閉並退出」才會退出並還原圖示。
Windows 支援時使用系統圓角。採用既有原生介面，沒有新引擎、動畫或輪詢。
介面預覽.png 是原生客戶區繪製，不包含系統圓角合成或陰影。

既有功能
所有標題、數量、狀態、版本及頁腳均由真實字體即時繪製；程式沒有使用參考圖當 UI 背景，也沒有縮放文字圖片。
英文展示字體 Russo One 只在程式內載入；資料字體 Bahnschrift、中文 Microsoft JhengHei UI。
Russo One 是本次採用的展示字體，不宣稱已辨識出參考圖片的原始字型。
小型資訊最小 12 像素；斜線、切角、十字、邊框與黃色旗角以抗鋸齒向量即時繪製。
保留大編號、斜線、標題、分類標籤、圖示數量、狀態點、黃色旗角、四個十字、點陣、側標、短黃線、左下斜紋、底部修訂與日期。
右上旗角貼齊實際視窗上、右邊緣；調整大小的感應區不再用面板遮住畫面。
檔案區與邊框有獨立留白；圖示和文字在內側裁切，捲動也不會跑到框線或裝飾上。
管理介面也採用同一套文字、字階、配色與分隔線。

文字與真實資料
01、02：分類的連續編號；新增、移除分類後重新編號。
WORKSPACE：你的分類名稱；雙擊標題可自行改名。
OBJECTS：此分類實際項目數；加入、移除、跨分類移動時更新。
STATUS：READY、LOCKED、STANDBY，對應可用、鎖定與微待命狀態。
OBJECT GROUP / LOCAL STORAGE SECTOR：目前桌面上的本機視覺分類。
SYS: LOCAL：本機設定資料；SECTOR：實際分類編號。
LOCAL / DISPLAY：框所在的實際螢幕。
GRID：實際橫向與直向格數；PATH: ORIGINAL：原始路徑不變。
REV：設定檔儲存修訂次數；日期：最後儲存日期；VER：程式版本。
預覽 PNG 使用驗證檔案與實際計數，並非你的桌面檔案截圖。

原始路徑
拖入桌面檔案、資料夾或捷徑後，只改變視覺分類與桌面圖示顯示。
不搬移、複製、重新命名原檔，也不建立額外捷徑。
例如 C:\Users\Player\Desktop\遊戲.lnk，分類前後路徑完全相同。
其他程式與檔案總管仍可透過原本路徑找到檔案。
原生桌面圖示會在籃子中顯示，框外不會再多顯示一份。

操作
雙擊框內項目開啟；右鍵可顯示原始所在位置、移至其他分類或移出分類。
拖曳標頭移動；靠近其他框 16 px 內，會磁吸貼齊或對齊邊緣。
拖曳四邊、四角或右下十字縮放。大小吸附完整格數，並盡量保持原框比例。
預設 14 × 4 格；最小 5 × 1 格。這台桌面最小 476 × 250 px，原本為 932 × 501 px，寬、高約各縮至一半。小尺寸會重新排列真實資訊文字，保留框線與裝飾，圖示間距不縮小；超過五個檔案可捲動。
這台桌面的原生圖示間距為 76 × 99 px，框內沿用此間距。
檔案超過可見格數，可使用滾輪、右側細捲動條、方向鍵與 PageUp/PageDown。
點擊黃色狀態圓點可鎖定／解鎖位置和大小。鎖定不妨礙加入檔案、開啟或捲動。
右上黃色旗角是分類選單，可改名、加入桌面檔案、鎖定、收合及移除分類。
分類設定可調整玻璃底色濃度 40–100%，預設 68%。底色獨立透明，文字與圖示保持不透明。
玻璃使用靜態暗色漸層與細微反光，桌布會透過玻璃底板顯示。
新增或移動框會先把被擋住的未分類桌面圖示擠開，再顯示整理框。
如果空間不足，操作不套用；原始檔案仍留在原位。
移除分類只取消分類；「暫停並還原圖示」或退出程式還原桌面圖示位置和排位設定。
關閉管理視窗會藏到系統匣；點系統匣可重新開啟。

資源與微待命
30 秒沒有操作進入微待命；閒置計時器停止，清空圖示快取，僅在進入待命時回收一次工作集。
待命時停止滑過檔案的高亮重繪，仍保留訊息處理，可立即響應點擊、拖曳、鍵盤與捲動。
沒有持續動畫、即時模糊、桌面截圖背景或循環輪詢。
桌面變動使用事件通知，只繪製可見檔案；圖示快取上限 64 份，不為每個檔案建立控制項。
0.4.0 的兩個玻璃框待命實測保留在驗證摘要.json 的 PreviousVersionBaseline；0.4.3 未重做這項量測。工作集與私有提交是不同指標；實際數字會隨系統與操作變動。

設定與復原
設定與原生圖示位置備份位於 %LOCALAPPDATA%\DesktopBaskets\state.json。
原始檔案不會放到此資料夾。
0.4.3 保留現有籃子的位置、格數、名稱和路徑引用，不會自動把現有框縮小。解鎖後拖曳右下角縮小，或在分類設定中指定 5 × 1 格。
意外退出後再次執行，會先恢復上次保存的圖示位置，再套用整理框。
移除程式前，請使用程式內的「退出並還原圖示」。
目前支援有實際路徑的桌面項目；資源回收筒等特殊 Shell 項目不在檔案拖入範圍。
