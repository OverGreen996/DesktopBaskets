# 0.5.3 桌面自由擺放

之前每次分類、桌面新增檔案或重新整理，都會重排所有未分類圖示；重新整理也可能把手動位置改回程式記錄的位置。

0.5.3 預設保留手動位置與空洞，只移開擋到籃框的圖示。避讓沿用原生格距，留在原螢幕；拖出籃框時，清楚可用的落點直接保留，碰到其他圖示或籃框才尋找附近空格。其他未受影響的圖示不移動。

分類管理新增「自動補齊桌面空位（會重排）」。新設定與舊版設定升級都預設關閉；勾選後立即補齊，後續分類、重新整理也會補齊。關閉只停止重排，不猜測先前的手動位置。

檔案路徑、籃子歸屬、原生右鍵與待機機制保留。桌面事件仍透過原有的 300 ms 合併處理，不新增輪詢。

## 驗證

`--free-layout-test` 使用正式的排列與修復判斷，包含手動空洞、非格線位置、三次重新整理判斷、新增／刪除檔案、分類後不補位、籃框避讓、拖出落點、碰撞回避、負座標雙螢幕、暫時不可用項目、升級預設值、設定保存與管理介面遮擋。

339 項檢查通過；另通過原有版面 498 項、可選補齊 310 項、分類保留 21 項與螢幕恢復 41 項。管理介面以正式控制項輸出畫面並檢視，確認一般與最小尺寸下兩個設定均可見。

`--refresh-test` 已改為驗證真實 Explorer 重新整理後保留手動位置；需要先暫停或退出正式程式才可執行，避免兩個整理程式同時改動桌面。上述自動檢查不等同於滑鼠操作驗證。

本機已安裝 0.5.3，使用安裝位置的執行檔完成原生測試：分類後三次 Explorer 重新整理保留鄰近位置；拖出項目再手動移到另一個位置，三次重新整理也未被拉回。選取清除、框與玻璃視窗保持顯示、落點附近顯示、檔案內容不變、原桌面座標與旗標還原均通過。

正式啟動後，3 個籃子的項目身分、原始路徑、位置、大小及 LOCK 保留，開機啟動偏好不變。唯讀檢查為 45 個框外圖示、41 個已分類圖示，待移動圖示 0 個，未與籃框重疊。
