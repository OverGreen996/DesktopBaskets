# 共享籃框（Windows 0.5.1／Android 2.0.0）

從分類管理按「＋ 共享籃框」。每台電腦有一個共享籃框與一個 Room，
可修改框的名稱、位置、格數、濃度及 LOCK。一般分類繼續純視覺整理原檔。

## 文字與檔案

- 在「文字」頁貼上內容，按「分享文字」。收到新內容不會覆蓋未送出的草稿。
  草稿保存於本機；重新開啟仍可繼續編輯。
- 拖檔案進框，或在「檔案」頁按「加入」。本機原檔留在原處，桌面原圖示
  依照原位分類規則收進框內；其他裝置看到共享資訊，需要時才下載。
- 本機檔案可直接開啟、拖出，或使用 Windows 原生右鍵。
  遠端檔案先按「開啟／下載」取得本機副本，再使用原生右鍵、開啟與拖出。
  遠端項目尚未下載時只是共享紀錄，不假裝成已在本機的檔案。
- 從框裡拉回桌面會還原桌面圖示並解除該原檔的共享；原檔路徑不變。
  移到一般分類也會解除共享。按「解除共享」可移除 Room 紀錄並還原本機
  桌面分類，原檔保留。
- 支援取消下載、串流、SHA-256、HTTP Range。未提供斷線自動續傳介面。
- 來源離線或檔案已變更會標記不可用，不會偷偷替換內容。

## 配對與接手 PocketDrop

按「裝置 / QR」→「顯示連線 QR」，手機開啟 Desktop Baskets Mobile 按
「掃碼連線」。兩端需在同一 Wi-Fi／LAN；也可使用八位驗證碼，電腦可用
QR 圖片加入。建立 Room 的電腦需保持開啟，手機 App 需在前景。
原 PocketDrop Android 仍相容，Windows 功能由 Desktop Baskets 接手，
不需同時執行 PocketDrop Windows。

新版手機 App 使用獨立應用程式 ID，可與原 PocketDrop 並存，不覆蓋原
App 或配對資料；首次使用需掃碼配對。手機下載目錄保留
`Downloads/PocketDrop`。詳見 [手機端說明](../android/README.md)。

如已用 PocketDrop，先正常退出它，進入「從 PocketDrop 接手」按「複製匯入」。
Desktop Baskets 複製 Room 資料、憑證與配對到新的本機資料夾，保留原資料。
同一 Windows 使用者帳號的 DPAPI 保護可沿用；不適用跨使用者帳號的搬遷。
如已建立新的 Room，匯入會拒絕覆蓋。切勿同時執行兩份相同身分的 Room。

本機資料：`%LOCALAPPDATA%/DesktopBaskets/sharing`。
下載：使用者的 `Downloads/DesktopBaskets`，每次下載存入獨立子目錄。
原 PocketDrop 已接收的檔案依舊保留於其原下載位置，匯入不搬動那些檔案。

## 資源與限制

共享框使用原生 Windows 控制項與獨立 Rust 核心，沒有 WebView2。
未新增共享籃框時不啟動核心；內容沒有改變時不因網路心跳刷新介面。
LAN 存活偵測仍需要低頻心跳，傳輸與完整性計算才進行實際檔案讀寫。
檔案雜湊使用單一工作佇列，避免一次拖入大量檔案產生大量工作執行緒。

沿用 PocketDrop 限制：每台來源最多 200 個檔案、單檔 16 GiB、每次拖入
100 個；不支援資料夾（先壓縮 ZIP）、雲端、Internet 穿透、iOS 或手機背景同步。
驗證碼與 QR 有效五分鐘且只能使用一次，保留憑證驗證、SRP 配對與撤銷機制。
